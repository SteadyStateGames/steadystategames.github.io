Advanced guide

Everyday instructions are in Help inside the app. These optional settings are for people who want more control.

Arrange your page

Adjust opens Settings / View. Turn the timer, separate work stopwatch, checklist, music controls, logo, top menu, or background on or off. Your choices save automatically. The small top-right arrow stays available to bring the menu back. Choose Show everything to restore the page.

Hiding a timer or music controls does not stop them. Pause first if you want to stop counting or playing. Minimizing keeps a smaller panel; hiding removes the panel entirely. Drag panels to move them and their bottom-right corners to resize. Settings / Timer can reset their positions and sizes.

Work stopwatch

The work stopwatch is a separate movable panel. Show it using Adjust. Its Start / Pause and minimize buttons affect only the work counter. The Pomodoro countdown and browser tab title continue independently. Open the panel's options button or Settings / Timer / Work & task tracking to choose a mode.

  • Independent: counts while its own stopwatch runs, even when the Pomodoro timer is paused. Pause it for breaks. It continues counting until paused, including time after closing the app.
  • With Pomodoro: counts only while the timer runs. Start the work counter once to enable it, then use the timer normally. Timer pauses do not add work time. An overdue timer counts only up to its deadline; it does not invent unattended cycles.

Linked mode retains work and break time separately. Include Pomodoro breaks changes the displayed total using that saved breakdown. Distraction time is red and separate from work. During a scheduled Pomodoro break, elapsed time belongs to the break rather than an objective or distraction bucket.

For a fresh day's total, choose Reset work totals in its options and confirm. This clears the work, break and distraction counters and pauses the work stopwatch, while keeping task records and the timer unchanged. Changing timer presets or resetting Pomodoro laps preserves work totals. Reset Pomodoro laps resets the completed-focus count and future long-break cycle without stopping the current countdown.

Optional objective records

Task time tracking and Task timestamps are off by default. Enable them in Settings / Timer / Work & task tracking. A task's play button selects it and starts the work counter if needed. Only one objective receives time at once; selecting another switches the objective. With Pomodoro mode still waits for the timer to run.

Objective time counts productive work only, excluding red distraction time, scheduled breaks and paused time. Checking an objective off stops its task clock and saves a completion timestamp when timestamps are enabled. Your daily work counter continues independently until you pause it. Reopening a task retains its time and clears its completion stamp. Resetting work totals keeps objective records; deleting a task or clearing completed tasks removes that task's record.

Optional timestamps record when a task was added, first timed, and completed. Older tasks receive no invented historical timestamps. Records save on this device and display in local time. Hover over the task's data line for full dates and times.

Your music

Open the music button or Settings / Music. Choose a built-in mood, or add MP3 / OGG files and name your personal library. Library playlists advance automatically and support shuffle. Scene music loops the song paired with your background.

Browser imports save locally on that device; they are not uploaded or synchronized. Clearing site data removes imports. Chrome and Edge can connect to a folder and retain read-only file handles; use Reconnect / refresh if permission expires or you add files. Other browsers import selected folder files. The desktop app remembers file locations and scans its connected folder on startup or refresh. Removing an entry leaves the original file intact.

Automatic distraction tracking

The optional Chrome / Edge helper watches the foreground tab in its browser. YouTube and TikTok count as distraction by default. Other tabs and applications count as work. It cannot detect phone use, another browser, or desktop video apps. Keep Pomodoro open, run the separate work stopwatch, and pause for breaks.

  1. Download the helper and unzip it to a folder you will keep.
  2. Open chrome://extensions or edge://extensions. Turn on Developer mode.
  3. Choose Load unpacked and select that folder.
  4. Reload Pomodoro and enable automatic tracking in Settings / Tracking.

To update an earlier helper, replace its files with the new download, keep a copy of any personal config, click Reload on its Extensions entry, and reload Pomodoro. Version 1.1 adds the browser tabs permission so custom sites can be classified.

Customize tracked sites and exceptions

Edit tracker-config.json inside your unzipped helper folder using a text editor. Save it, click Reload on the helper's Extensions entry, and reload Pomodoro. You do not need to edit the app or the website.

Example: add Facebook, allow one work video, and allow a YouTube series played from its playlist:

{
  "tracked_sites": [
    "youtube.com", "youtu.be", "tiktok.com", "facebook.com"
  ],
  "allow": {
    "youtube_video_ids": ["YOUR_VIDEO_ID"],
    "youtube_playlist_ids": ["YOUR_PLAYLIST_ID"],
    "rules": [
      {
        "site": "facebook.com",
        "path_prefix": "/groups/YOUR_WORK_GROUP/"
      }
    ]
  }
}
  • tracked_sites takes hostnames without https:// or paths. A hostname includes its subdomains; facebook.com also matches www.facebook.com. Remove an entry to stop tracking that site. An empty array disables site matching.
  • youtube_video_ids allows the ID after v= in a watch link, or after youtu.be/. The exception also applies to Shorts, live and embedded links for that ID, regardless of extra URL parameters.
  • youtube_playlist_ids allows the value after list=. Open a series through its playlist so the playing URL retains list=. A standalone link without that playlist parameter will still count as distraction unless its video ID is also allowed. The helper does not fetch playlist membership or channel information.
  • Allow rules are checked before distraction is counted. Every condition within one rule must match. Matching any allow rule counts that page as work. These rules do not pause the stopwatch.
  • Use valid JSON: double quotes, commas between entries, no comments or trailing commas. A missing or invalid config falls back to the default YouTube / TikTok rules. The helper's service-worker console shows the config error.

Rules can use an exact path, a path_prefix, and exact query values. Paths and query values are case-sensitive. A rule containing only site allows that entire site.

{
  "site": "youtube.com",
  "path": "/watch",
  "query": { "v": "YOUR_VIDEO_ID" }
}

Privacy and limits

The helper uses the tabs permission to read the foreground tab's URL for local matching. It does not store URLs, titles or page contents, send browsing data to a server, or block websites. Only work/distraction transitions are kept in browser-session storage, up to 2,000 transitions. Incognito tabs are excluded. Delayed transitions are reconciled when the Pomodoro canvas resumes. Disable automatic tracking in Settings, or disable/remove the helper on the browser's Extensions page.

Saving, audio and shortcuts

Tasks, settings, layouts and timer state belong to that browser/device. They do not sync across devices or with the Windows edition. A running countdown restores its deadline when reopened. Keep the page open for chimes; the browser may suspend audio while the device sleeps. Music waits for Play each time the app opens.

Space starts or pauses the timer. F11 toggles fullscreen. Escape closes a menu or exits fullscreen. When typing in a text field, normal text entry takes priority.
